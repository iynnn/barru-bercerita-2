# 📊 Barru Bercerita v2

> **Portal Visualisasi Data Statistik & Sistem Informasi Pelayanan Statistik Terpadu (PST)**  
> *Badan Pusat Statistik (BPS) Kabupaten Barru*

`Barru Bercerita 2` adalah platform web terpadu yang dirancang untuk memvisualisasikan indikator-indikator makro pembangunan Kabupaten Barru secara interaktif, menyajikan narasi analisis data bertenaga AI, serta memfasilitasi operasional Pelayanan Statistik Terpadu (PST) BPS Kabupaten Barru.

---

## ✨ Fitur & Kapabilitas Utama

### 📈 1. Dashboard Visualisasi Data Makro
- **Visualisasi Interaktif**: Menyajikan tren deret waktu (*time series*) indikator strategis daerah seperti PDRB, Tingkat Kemiskinan, Tingkat Pengangguran Terbuka (TPT), Indeks Pembangunan Manusia (IPM), Angka Harapan Hidup (AHH), Rata-rata Lama Sekolah (RLS), dan Gini Ratio.
- **Komparasi Indikator**: Fitur perbandingan tren antar-indikator statistik dalam satu grafik.
- **Ekspor Data & Grafik**: Pengguna dapat mengunduh grafik visualisasi dalam format gambar (PNG) serta data mentah dalam format CSV / Excel.

### 🤖 2. Narasi "Barru Bercerita" (AI Data Storytelling)
- **Narasi Otomatis**: Mengubah angka-angka statistik resmi BPS menjadi narasi cerita yang komunikatif dan mudah dipahami publik.
- **Rekomendasi Kebijakan**: Menyediakan rekomendasi taktis bagi Pemerintah Daerah Kabupaten Barru berdasarkan analisis tren data historis.

### 🏛️ 3. Portal Pelayanan Statistik Terpadu (PST)
- **Katalog Layanan Publik**: Informasi lengkap mengenai konsultasi statistik, permohonan data mikro, rekomendasi statistik, dan pengaduan konsumen data.
- **Akses Cepat Layanan**: Integrasi ke portal-portal layanan resmi BPS.

### 📅 4. Manajemen Jadwal Jaga & Presensi Petugas PST
- **Penjadwalan Piket Otomatis**: Sistem rotasi jadwal harian untuk Petugas PST (Tim K1 & K2), Tim Pengaduan (P), dan Tim Rekomendasi (R).
- **Presensi Digital Petugas**: Fitur *check-in* kehadiran harian bagi petugas piket yang bertugas.
- **Tukar Jadwal Mandiri (*Shift Swap*)**: Alur pengajuan tukar jadwal antar-petugas dengan mekanisme konfirmasi langsung (ACC) dari petugas target maupun admin.
- **Kelola Data Petugas**: Manajemen profil petugas dan dukungan impor/ekspor data via spreadsheet Excel (`.xlsx` / `.csv`).

---

## 🛠️ Ringkasan Teknologi

- **Frontend**: React, React Router (`HashRouter`), Vanilla CSS (Glassmorphism & Dark Mode)
- **Grafik & Visualisasi**: Chart.js & `react-chartjs-2`
- **Manajemen Spreadsheet**: SheetJS (`xlsx`)
- **Backend API**: PHP REST API & Database MySQL
